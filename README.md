## Featured Projects

<details>
<summary><strong>DentalCare — Dental Management System</strong></summary>

<br/>

DentalCare is a full-stack dental clinic management system designed to centralize clinic operations, patient care workflows, appointments, treatment records, digital prescriptions, invoices, billing, and reporting.

The platform provides dedicated role-based experiences for Admin/Receptionist, Dentist, and Patient users, allowing each user type to manage the workflows relevant to them.

| Dimension | Details |
|:---|:---|
| **Stack** | React.js 18, Vite, Tailwind CSS, Node.js, Express.js, MongoDB, Mongoose |
| **Scale** | Role-based workflows for Admin/Receptionist, Dentist, and Patient users |
| **Performance** | REST APIs, pagination, filtering, dashboard statistics, and responsive frontend architecture |
| **Security** | JWT authentication, bcrypt password hashing, protected routes, and role-based authorization |
| **Impact** | Digitizes appointments, patient management, treatments, prescriptions, invoices, payments, and clinic reporting |
| **Repository** | [View Repository](https://github.com/abhay269/dentalcare) |
| **Live Demo** | [Open DentalCare](https://dentalcare-ten-dun.vercel.app) |

### Core Capabilities

- Admin and receptionist dashboard with live statistics and charts
- Patient creation, editing, search, filtering, pagination, and management
- Dentist account creation and profile management
- Appointment booking, rescheduling, cancellation, and status management
- Dentist dashboard with daily schedules and assigned appointments
- Patient lists and medical history access
- Treatment record creation and management
- Digital prescriptions with multiple medicines and print support
- Invoice creation and billing management
- Payment status tracking with payment method support
- Printable invoices and prescriptions
- Patient dashboard for appointments, treatments, prescriptions, and billing
- Clinic settings and profile management
- Reports and analytics using Recharts
- Demo data seeding for local development and testing

DentalCare demonstrates practical product engineering across frontend development, backend API design, authentication, database modeling, role-based access control, reporting, and deployment-oriented full-stack architecture.

</details>
